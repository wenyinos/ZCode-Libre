ZCode-Libre

ZCode 的社区分支，只做该做的改动

An independent community fork of ZCode

保留完整功能与上游可同步性；遥测与厂商服务默认关闭，模型用你自己的 API Key 直接接入，会话与设置仍与官方客户端共用同一份数据。

Full upstream feature set, kept in sync. Telemetry and vendor services are off by default, models connect with your own API key, and sessions stay shared with the official client.

默认关闭的东西

Off by default

上游这些能力都保留在代码里，只是不再默认启用；把开关打开即恢复原行为。

Upstream keeps the code — it is simply not enabled by default. Flip the switch to restore it.

遥测与监控Telemetry

数仓上报、ARMS、OTLP 全部默认关闭；采样器注册也一并纳入总开关，不留后台常驻定时器。

Warehouse reporting, ARMS and OTLP are off; sampler registration is gated by the same switch, so nothing keeps polling in the background.

官方账号体系Account sign-in

不要求登录，也不再用账号状态作为启动门禁；模型通过 API Key 直接接入。

No sign-in required, and account state no longer gates startup. Models connect directly with an API key.

厂商服务Vendor services

反馈、会话分享、套餐购买入口、插件市场远端源默认关闭；本地内置插件不受影响。

Feedback, conversation sharing, plan purchase and the remote plugin marketplace are off; bundled plugins still work.

相对上游多做的事

What this fork adds

模型额度显示Model balance

用已配置的 API Key 查询 DeepSeek、GLM Coding、Kimi、MiniMax、OpenRouter 的余额与套餐余量；未配置的厂商自动隐藏。

Query balances for DeepSeek, GLM Coding, Kimi, MiniMax and OpenRouter using the keys you already configured. Providers without one stay hidden.

透明的紫色主题Translucent theme

「紫夜」主题让桌面与窗口材质透出来，色板取自 Zed 的 Nightfox 主题包。Web 端自动改用纯色。

A "Dusk" theme reveals the desktop through vibrancy and acrylic, with a palette taken from Zed's Nightfox pack. The web build falls back to solid colour.

更新只检测，不代装Check-only updates

检测本仓库的 Release 并引导你前往下载，不在应用内下载或安装——避免被装回官方版本。

Detects a newer release and sends you to the download page. Nothing is installed in-app, so you can never be silently switched back to upstream.

与官方客户端的边界

How it relates to upstream

会话与模型设置 存放在 .zcode 数据根，与官方客户端共用同一份，装上即可读到既有对话与配置。 Sessions & settings Shared through the .zcode data root, so existing conversations and configuration carry over.

本地构建

Build locally

需要 Git、Node.js 24.14.0 与 pnpm 10.33.2，版本以仓库的 mise.toml 为准。

Requires Git, Node.js 24.14.0 and pnpm 10.33.2; mise.toml is the source of truth.

git clone https://github.com/wenyinos/ZCode-Libre.git
cd ZCode-Libre
pnpm bootstrap
pnpm dev:desktop     # 桌面开发 / desktop dev
pnpm bundle:desktop  # 打包当前平台 / package for this platform
