ZCode-Libre
基于 ZCode 的社区分支
数据跟官方共用，
发行渠道各自独立
对话记录、模型设置和凭据都在原来的位置，不用迁移也不用重新登录；界面偏好各存各的，所以两个版本能同时装、同时开。
遥测与厂商服务默认关闭 账号登录、会话分享、反馈工单、插件市场远端源，各项在设置里都有开关
模型只走你自己的 API Key 凭据直连模型服务，不经过任何账号体系
命令行版独立发行 TUI + Web 一套包，覆盖 macOS arm64 与 Linux x64 / arm64；下载本地安装包，离线也能装
更新只做检测 查到新版只给下载页，装不装由你决定，不会被换回官方版本
额外的界面定制 「紫夜」主题在 macOS 与 Windows 下半透明；常用 coding plan 额度直接显示

不收集就是不收集，没有「匿名统计」这类折中。
